# sales-forecasting-machine-learning
Machine learning project to forecast retail sales using historical data
# Sales Forecasting using Machine Learning

## Objective
Predict future retail sales using historical transaction data.

## Project Description
This project uses machine learning techniques to forecast sales trends based on historical retail data.

## Technologies
- Python
- Pandas
- Scikit-learn
- Prophet
- Matplotlib

## Project Structure

data/
Dataset files

notebooks/
Exploratory analysis and forecasting models

images/
Charts and prediction visualizations

## Expected Outcome
The model predicts future sales and helps businesses improve inventory planning.
